# Student Management System

A simple Python-based Student Management System that allows users to manage student records using JSON file storage.

This project is beginner-friendly and demonstrates concepts like:

* File handling
* JSON data storage
* Functions
* CRUD operations
* Conditional statements
* Loops
* Python dictionaries and lists
Features

✅ Add Student Information
✅ View All Students
✅ Search Student by ID
✅ Update Student Details
✅ Delete Student Record
✅ Generate Student Report Card
✅ Calculate Percentage and Grade
✅ Store Data Permanently Using JSON

Technologies Used

* Python
* JSON
* File Handling
* OS Module

## How to Run the Project

### 1. Clone the Repository

```bash

```

### 2. Open the Project Folder

```bash
cd project-folder
```

### 3. Run the Python File

```bash
python main.py
```
